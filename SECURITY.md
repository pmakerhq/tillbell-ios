# Security policy

## Supported versions

Tillbell for iOS has no release yet. Once there is one, only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through [GitHub's private vulnerability reporting](https://github.com/pmakerhq/tillbell-ios/security/advisories/new). Include the affected version, what you observed and, if you can, how to reproduce it.

You will get an acknowledgement as soon as possible. A confirmed vulnerability is fixed in a new release and disclosed in a published security advisory.
